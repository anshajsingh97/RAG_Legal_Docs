# RAG Legal Documents Assignment

## Submission Overview
This repository contains the submission for the **Retrieval-Augmented Generation (RAG) Legal Documents Assignment**.

The objective of the assignment is to process and analyze a collection of legal documents and build a Retrieval-Augmented Generation (RAG) pipeline for legal question answering.
